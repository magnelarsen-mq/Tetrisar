STAR TETRIS – META QUEST PACKAGE

Direkte fil:
- star_tetris_quest.html kan lastes ned som én selvstendig HTML-fil.
- Meta anbefaler normalt at Quest-webapper kjøres fra en HTTPS-adresse.

Quest/PWA:
1. Last opp innholdet i denne ZIP-filen til en HTTPS-host (f.eks. GitHub Pages, Vercel eller Netlify).
2. Åpne URL-en i Meta Quest Browser.
3. Trykk START FULLSKJERM i spillet.
4. Pakken inneholder manifest og service worker slik at den kan brukes som grunnlag for en Quest PWA.

For ekte APK/sideload må appen pakkes/signeres med Android/Meta Quest-verktøy.
